# Segurança e privacidade

Se encontrar uma falha que possa expor registros de saúde, backups, tokens, credenciais ou inscrições de avisos, **não abra uma issue pública**. Envie um relato para [ewanderson.flaviano@gmail.com](mailto:ewanderson.flaviano@gmail.com) com passos para reproduzir usando dados fictícios. Não envie backups ou dados de outra pessoa.

Problemas comuns de interface e comportamento podem ser relatados nas [issues](https://github.com/ewflaviano/biorotina/issues). Evite anexar capturas ou logs que mostrem dados pessoais.
